# W8 ? parallel PSD/PSB import

Implemented on `perf/w8-psd`, following W1 from `be4168c`.

- Pixel/mask decoding is independent per record and parallel on native targets. IDs, layer tree, effects and warnings are assembled in deterministic source order; wasm uses the sequential path.
- Raw and PackBits color/alpha channels decode in globally tile-aligned bands (normally 256 rows), straight into band surfaces. Rayon map_init reuses planar buffers per worker. ZIP/predicted ZIP and malformed-band paths retain the established decoder and warning behavior.
- Compatibility composite is emitted before layer pixel decoding. The UI shows it as a busy/read-only opening document, then replaces it with the fully imported document. Cancel removes the preview. Progress updates per completed layer.
- Native PsdFile::from_reader parses metadata and reads encoded payloads channel by channel, without retaining a full-file Vec. Section and global Lr16/Lr32/Layr layer storage are supported. Encoded channels remain in the parsed model until conversion finishes; this is not a demand-paged/lazy PSD document model.
- Exact compose bounds cache is primed for decoded surfaces while pixels are resident, before handoff. Cache misses scan outside its shared mutex, so an import does not hold that mutex across scratch reads or full-tile scans.

Switches: `PHOTOCRAFT_PSD_PARALLEL=0`, `PHOTOCRAFT_PSD_BANDS=0`, `PHOTOCRAFT_PSD_PREVIEW=0`, `PHOTOCRAFT_PSD_STREAM=0`, `PHOTOCRAFT_PSD_PRIME_BOUNDS=0`; `PHOTOCRAFT_JOBS=0` disables asynchronous UI I/O.

Files: io psd_import/psd_bands/lib + native rayon dependency, psd stream parser + crate-private record parser access, compose bounds cache locking, desktop worker hook.

Validation: native cargo check of desktop/UI/engine/io passed before the final lifecycle-only guards; integrated build/layers/wasm remains required. No tests, benchmark, timing, pixel comparison or UI smoke test was run, as requested. No opening-time target is claimed.

Limits: encoded PSD channels still live in memory until document construction completes. Preview publication follows parsing of the encoded layer payloads; it does not seek directly to the end-of-file composite ahead of parsing. Cancellation during initial parsing/merged decode waits for that phase; layer work checks between layer tasks. ZIP still needs complete channel planes. Native stream allocations are capped at 2 GiB per individual payload and fail gracefully. Pack loading keeps its lazy behavior; native packs do not eagerly prime all full-resolution source tiles.

Static integration follow-up: native packs created before persisted exact bounds hints were introduced still require a cold content-bounds scan if their sources have no stored hints; lazy pack import deliberately does not eagerly read all source tiles. The newly saved pack path can carry those hints. No runtime measurement was performed.
