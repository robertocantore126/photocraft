# W1 ? native document jobs

Implemented on `perf/w1-jobs`, based on `be4168c`.

- Engine `begin_edit`/`commit_edit` snapshots, origin-document identity + Arc guards, history, channel restrictions, coalescing, damage, journal and post-command hooks.
- CommandSpec job preparation for filter commands, Image Size, Canvas Size, merge/flatten and Smart Object rasterization. Ordinary algorithm filters resolve session inputs before entering the worker. Other heavy commands use an isolated session snapshot.
- UI Jobs queue runs native workers; collects and commits on the UI thread; reports progress and handles Esc. Busy documents reject edits, undo/redo, layer selection and close; another document can stay active. Automation remains synchronous. Wasm executes jobs inline.
- Native path opens and saves use additive Send+Sync worker services. Saves stage a complete file beside the destination, check cancellation, and rename; they never delete the original destination first. Background native saves compact the pack rather than append; disabling jobs restores the old incremental path.
- Save/close/quit prompts wait for asynchronous save completion, including failure/cancellation.

Switch: `PHOTOCRAFT_JOBS=0` restores synchronous dispatch/open/save.

Files: engine jobs + command metadata constructors, algo progress and tiled loop, UI jobs/io_jobs/lib/file_open/discard_ui/menus, desktop services.

Validation: native `cargo check -p photocraft -p photocraft-ui-egui -p photocraft-engine -p photocraft-io` passed. No tests, benchmarks, UI smoke tests or measurements were run, per request. Final integrated build/layers/wasm remain the integration gate.

Limits: tile algorithms check cancellation between tiles. Resize, merge, rasterization, parsing and serialization are interruptible at job/staging boundaries, not inside every underlying kernel or filesystem read. Their progress is coarse. Failed thread startup releases busy state. No performance or responsiveness target is claimed. W8 adds composite previews and streaming/parallel PSD import separately.
