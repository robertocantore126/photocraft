## 1. Reference layers, Paint Bucket, Ctrl+F

- `Layer::reference` (doc, `.pcraft` manifest, `document.inspect`). Layer › Reference Layer
  (`layer.reference`, checkmark), Layers context menu "Set as / Unset Reference Layer", an "R"
  badge on the thumbnail.
- Magic Wand and Paint Bucket: options-bar **Sample: Current Layer / Reference Layers / All
  Layers** (`"sample"` param; `sampleAllLayers` still works). Reference with no reference layer
  falls back to the current layer.
- Paint Bucket **Expand** (px): the fill grows under the anti-aliased line art
  (`algo::selection::expand_region`, `algo::paint::fill_region`). The sampled path honours
  Lock Transparency.
- **Edit › Fill Foreground, Ctrl+F** (`edit.fillForeground`): with a selection, fills it with the
  foreground colour; without one, fills the closed area under the pointer sampling the reference
  layers, expand ≥ 1 px (the UI adds the pointer position, tolerance and expand).

## 2. Pixel Brush

`Tool::PixelBrush` in the Brush flyout (B). `paint.stroke` `"pixel": true` → aliased, hardness
100 %, whole-pixel sizes, dab centres on the pixel grid (`BrushSettings::pixel_snap`), no
texture/scatter/dual. **Pixel Perfect** (default on, `pixel_perfect`) removes the middle pixel
of L corners at 1 px, holding one pixel back (`dynamics::PixelGrid`, flushed on finish and in the
live tail preview). First use: 1 px, 100 % opacity, smoothing 0.

## 3. SAI Brush

`photocraft_paint::sai` (own model): each dab interpolates the canvas towards a carried colour.
Blending mixes in the canvas colour in proportion to the paint present; Dilution lowers the
paint alpha and lets the alpha follow the canvas (watercolor thins out); Persistence keeps the
carried colour; Density = brush opacity; Keep Opacity. Shape map (SAI blotmap) breaks the dab
edge, texture multiplies coverage; both tiled in document space.

- `Tool::SaiBrush` (Brush flyout, droplet icon). Options bar: Brush / Watercolor / Marker preset,
  Size, Density, Blending, Dilution, Persistence, Keep Opacity, Shape + strength, Texture +
  strength + scale, reload button. `paint.stroke` `"sai": {…}`; live preview through
  `LiveStroke` (same painter, so live = commit; the smoothing catch-up appears on release).
- Maps: `%APPDATA%\Photocraft\sai-textures` (`PHOTOCRAFT_SAI_TEXTURES`), any .bmp/.png/.jpg,
  by file stem (`engine::sai_textures`, own BMP reader). Rob's Acrylic, Bark2, Crust, Acuarelle
  are copied there. Nothing bundled in the repo.
- Speed (3000², 100-point stroke): 300 px 251 ms (normal brush 51 ms), 60 px 127 ms. RGBA layers
  skip per-pixel conversions.

## 4. Linework layer

- `Layer::linework: Option<Arc<Linework>>` (doc `linework.rs`): strokes = control points
  (x, y, width), colour, curve/polyline, closed. The layer stays a pixel layer whose pixels are
  the strokes rendered, so compositing, GPU, thumbnails and PSD export are unchanged. `.pcraft`
  saves the strokes; PSD gets the pixels.
- Commands (`engine::linework_cmds`): `layer.new.linework`, `linework.addStroke` (RDP
  `simplify`), `linework.eraseAt` (whole strokes), `linework.editStroke` (delete, points,
  colour, width, translate, move/resize/delete one point), `layer.rasterize.linework`.
  A new stroke is painted on top; other edits re-render only the dirty rectangle.
- `Tool::Linework` (own toolbar slot, spline icon; `linework_ui.rs`): Pen (pressure → width),
  Eraser, Curve, Line (click points, Enter / Finish, Esc), Edit (drag a point, ⇧-click deletes it,
  ⌘-drag moves the stroke), Pressure (drag a point up/down), Weight, Color. Width, Pressure,
  Simplify in the options bar. Using it on a non-linework layer creates a Linework layer first.
- Pixel tools on a Linework layer ask to rasterize it (drops the strokes). Thumbnail badge.

## 5. Sugimori watercolour set

`LayerRole` (doc `roles.rs`, saved in `.pcraft`): SugiSketch, SugiLine, SugiBase, SugiColour,
SugiPaper, SugiSoftLine{radius}. Orange role badge on the thumbnail; the set's group shows a
palette icon. Layer › Sugimori › Make Normal Layer clears the role.

- **Layer › New › Sugimori Watercolour Set** (`layer.new.sugimoriSet`): group "Sugimori" =
  Grey Background (solid fill), Sketch (35 %), Base (white), Watercolour (clipped), Paper (pattern
  fill from the `Acuarelle` map, Multiply 25 %, clipped; skipped if the map is missing), Soft
  Line (40 %, clipped), Line (Linework, reference). The Line is selected and the Linework tool
  picked.
- **Generate Base from Line** (`sugimori.generateBase`, expand 0): fill from a transparent canvas
  corner on the line's pixels, inverted, white on the Base.
- **Soft Line**: the line blurred (Gaussian, radius 4) regenerated after every linework edit of
  the set's line; `sugimori.refreshSoftLine {radius?}` by hand.
- Selecting the Line picks the Linework tool; selecting the Watercolour picks the SAI Brush as
  Watercolor.

## Known gaps

- Linework with strongly varying width shows faint ridges on the thick parts (dabs of growing
  size); a polygon outline renderer would be exact.
- A thin light rim can show just outside the line (base anti-aliased edge under the line's edge).
- Filters run on a Linework layer change its pixels, but the next linework edit re-renders the
  edited area from the strokes.
- SAI `.ini` presets are not imported yet; OldSugi / OldWater values are guesses (the guide shows
  them only as an image).
- The base is not regenerated automatically when the line changes (menu command).
- Ctrl+F semantics are my proposal (spec question 1).
