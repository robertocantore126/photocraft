# W7: deferred effect inputs (2026-10-09)

The live GPU canvas can build CPU layer shapes and exact distance fields on two dedicated native workers. GPU texture uploads and map programs remain on the render thread. The compositor used by export stays synchronous by default, so an export never captures a partially settled preview.

Changed files: `crates/gpu/src/fx_jobs.rs`, `crates/gpu/src/lib.rs`, `crates/ui-egui/src/gpu_canvas.rs`.

The queue has eight request slots, two reply slots, at most twelve tracked requests and a 256 MiB combined input reservation. Each request is keyed by document, layer/cell, region, source tile identities and effect program settings. Changed requests wait for an outstanding older computation and discard its result; closing a document drops its tracked work. Worker panics become errors. Failure to create workers, a disconnected worker or an individual window beyond the reservation limit falls back to the synchronous path and logs the reason. Nested group rendering and wasm stay synchronous.

While inputs are pending, mapped effect passes use zero opacity. Completion invalidates the affected display rectangles independently of document history. The live canvas keeps requesting frames while jobs are pending. CPU shape and distance-field builders are the existing exact implementations; no jump-flood approximation was added.

Set `PHOTOCRAFT_ASYNC_EFFECTS=0` before launch to restore synchronous effect inputs. Native headless GPU compositors remain synchronous unless callers explicitly enable deferred effects.

Scope: W7 step 1 implemented through a private L3 worker queue because the GPU crate cannot depend on the L5 engine job scheduler. W7 step 2 (optional GPU jump flooding) remains open. GPU map passes, upload time, planning, nested group evaluation and over-limit fallback can still occupy a frame. No frame-time or convergence target is claimed.

Validation: `cargo check -p photocraft-gpu -p photocraft-ui-egui` passed on native Windows. Full build, wasm and layer checks remain pending integration. Tests, benchmarks and measurements deliberately skipped at the user's explicit request. No UI smoke test has been performed.
